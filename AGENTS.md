# Dzen Agent — правила разработки

## Цель продукта

Dzen Agent — простое локальное приложение, которое помогает создавать, хранить и готовить
статьи в Яндекс Дзене. Любая публикация или планирование публикации требует явного действия
пользователя. V0 заканчивает автоматизацию после заполнения редактора.

## Архитектура

- `dzen_agent/ui.py` — интерфейс Streamlit.
- `dzen_agent/ai.py` и `dzen_agent/prompts/` — AI-логика и редактируемые инструкции.
- `dzen_agent/database.py` и `models.py` — SQLite и модель статьи.
- `dzen_agent/browser/` — Playwright и отдельно вынесенные селекторы Дзена.
- `dzen_agent/config.py` — переменные окружения и локальные пути.
- `tests/` — быстрые проверки основных контрактов.

## Правила

1. Сохраняйте систему простой; не добавляйте сервисы и абстракции без практической причины.
2. Сохраняйте обратную совместимость данных, настроек и пользовательского сценария.
3. После изменений запускайте как минимум `pytest`, `ruff check .` и проверку импортов;
   при изменении UI также выполняйте smoke-test запуска Streamlit.
4. Не удаляйте рабочий функционал без явной причины и описания миграции.
5. Сначала исправляйте существующую реализацию; не переписывайте весь проект с нуля.
6. Никогда не храните секреты в коде и не добавляйте `.env` в Git.
7. Не добавляйте автоматическое нажатие кнопок публикации. CAPTCHA, 2FA и вход остаются
   ручными действиями пользователя.
8. Для облачных задач используйте существующий checkout; не создавайте Git worktree без
   явного запроса пользователя.
