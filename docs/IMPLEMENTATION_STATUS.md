# Состояние интеграций

## Проверено локально

- Обновление V0 SQLite без удаления статей, резервная копия и повтор миграции.
- Версии промптов, безопасные переменные, восстановление старой версии.
- CSV: UTF-8, BOM, Windows-1251, UTF-16, разные разделители, ручное сопоставление колонок.
- Структурированные AI-результаты и учёт стоимости на тестовых HTTP-ответах.
- Полный pipeline до REVIEW, возобновление после сбоя и отсутствие повторной генерации готового.
- Неподтверждённые сетевые запросы не повторяются автоматически.
- Локальные изображения, загрузка своей обложки, снятие утверждения после редактирования.
- Все восемь разделов Streamlit, сохранение черновика и версии промпта.
- Груминг: изолированная история по неделям, компактный контекст, предложения с явным
  применением/отклонением, проверка устаревших версий, совместная перестановка дат.
- Остановка PLAN_REVIEW перед Writer в REVIEW/MANUAL и пропуск в AUTOPILOT.
- Адресное REFRESH_RESEARCH с восстановлением после сбоя без повторной оплаты готового.
- Миграция схемы 1 → 2 сохраняет статьи, планы, расходы и старые завершённые этапы.
- Миграция 2 → 3 сохраняет старые JSON Analytics и версии промптов без изменений.
- Полный Analytics 1.0: типы, диапазоны, ссылки, входные идентификаторы, периоды и метрики.
- Передача discovery_brief в Discovery и planner_brief в Planner; новый порядок с Research
  после утверждения плана. Старые запуски продолжаются в прежнем порядке.
- Недостаточные данные блокируют платный поиск; явный повтор аналитики сохраняет расходы
  и исходный результат. Недействительный оплаченный ответ не оплачивается повторно при продолжении.

Чат и его расходы проверяются на mock HTTP-ответах AITUNNEL; это не проверка качества
реальной модели. Изменения концептов через груминг доступны до начала WRITE;
после этого чат остаётся инструментом обсуждения. Дзен-адаптер и автоматическая CSV-выгрузка
в этой доработке не менялись.

## AITUNNEL

Публичные каталоги chat и images фактически получены без ключа 17.10.2026.
Модели по умолчанию выбираются по текущему каталогу, а не по устаревшему списку в коде.
Частные методы balance/key/stats и платные генерации требуют AITUNNEL_API_KEY.
В этой доработке платные генерации проверялись только на mock HTTP-ответах.

## Дзен: незавершённая интеграция

Фактически открыт Chromium с локальным профилем. Старый URL V0
`https://dzen.ru/profile/editor/id/new` вернул «Такой страницы не существует».
На главной Дзена доступен ручной вход.

**Создание отложенной публикации, загрузка обложки в Дзен, верификация и обновление
отложенной публикации пока не реализованы в живом адаптере и не проверены.**
`browser/scheduling.py` содержит проверяемый контракт и учёт намерения/результата,
но не выдаёт заглушку за рабочую интеграцию. Без подключённого проверенного адаптера
публикации блокируются, статус SCHEDULED_VERIFIED не выставляется.
Автоматический экспорт CSV также требует проверки реальной кнопки;
рабочий путь сейчас — ручной импорт.

Для завершения нужен вход владельца в Студию. После входа разработчик должен:
1. Проверить адрес редактора и реальные селекторы; сохранить их отдельно.
2. Реализовать живой адаптер создания, загрузки обложки и отложенной публикации.
3. Проверить одну тестовую статью с датой далеко в будущем и её стабильным URL.
4. Проверить обновление этой же статьи и сохранение времени.
5. Подключить адаптер к CLI и UI; только затем разрешить автономную отправку.

CAPTCHA и 2FA выполняются владельцем. Пароли и cookies не попадают в Git.

## Ограничения текущей версии

- Analytics v3 сохранён дословно. Для Discovery нужен отдельно согласованный промпт,
  добавляемый через UI; приложение не подменяет его промптом Research. Остальные активные
  промпты не переписывались. Качество реальных ответов моделей здесь не проверялось.
- Один материал на выбранный день, 1–7 материалов в неделю.
- Готовые результаты и конфигурация фиксируются на запуск. Изменения моделей/промптов
  можно отдельно применить к незавершённым этапам. Для нового платного повторения
  предусмотрено явное подтверждение в интерфейсе.
- Источники проверяются по citations/annotations/search_results поискового API.
  Это не равнозначно полной ручной фактологической проверке содержимого источников.
- Мягкий бюджет проверяется перед каждым новым запросом. Один запрос может пересечь
  границу бюджета; жёсткий лимит устанавливается в кабинете AITUNNEL на ключ.
- После неясного timeout/5xx запрос останавливается, чтобы не списать средства повторно.
- Windows Task Scheduler требует включённый компьютер и вход пользователя в Windows.
- AUTOPILOT готовит материалы, но завершение полного цикла зависит от живого адаптера Дзена.
